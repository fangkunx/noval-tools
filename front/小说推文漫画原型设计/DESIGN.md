# 小说推文漫画工作台｜原型设计文档

## 1. 交付范围

本目录包含一个可直接打开的静态 Web 原型：`index.html`。原型覆盖参考文档中的六个核心模块：账号池、提示词、画风库、小说库、分镜台、资产库；支持模块切换、新建弹窗、账号配置弹窗、漫画设置弹窗、批量操作提示和提示词复制等关键演示交互。

## 2. 参考资料与指令边界

参考资料是压缩包内的《小说推文漫画设计.md》及其附件截图。文档中的条目被视为产品需求与界面参考：

- 账号池：卡片查询、自定义线路、技术标准、能力、API 地址、ApiKey、模型编号、显示名称、启用。
- 提示词：按分类筛选、卡片查询、新增标题/分类/内容。
- 画风库：卡片查询、新增中文名称/输出画风描述/单张画风图片。
- 小说库：卡片查询、新增书名/内容、小说编辑、清理序号、导入剧本。
- 分镜台：预设、智能角色/场景/道具、一键形象、漫画设置、批量推理、批量生图。
- 资产库：角色/场景/道具分类、小说筛选、卡片展示。

截图里的账号名、小说名、示例文本、数量、ID 和日期仅作为视觉占位数据，不视为需要逐字复制的额外指令；原型用同类占位内容维持版式密度。

## 3. 视觉规范

| 项目 | 规范 |
|---|---|
| 画布 | 桌面端优先，最小可用宽度约 1100px；小屏时分镜台降为单列 |
| 背景 | `#151515` 主背景，`#111111` 顶栏，`#292929` 卡片与侧栏 |
| 强调色 | 青绿色 `#00F1C3`：可用、选中、主要操作；金色 `#F5CA37`：VIP、关键批处理、创建操作 |
| 圆角 | 卡片 10px，控件 4–7px，虚线新增卡片 2px 边框 |
| 字体 | 中文桌面 UI，正文 14px；标题 28px；次要信息 11–13px |
| 信息密度 | 卡片化列表、标签化筛选、短文本摘要，接近参考稿的高密度工作台 |

## 4. 核心页面与交互

### 小说库

左侧剧本列表固定显示当前剧本；主区使用分类标签、搜索和卡片网格。点击“创建小说”弹出新建表单，点击选择进入选择模式。

### 账号池

账号以服务卡片展示，支持文本/图像能力标签与启用状态。点击“密钥与设置”打开配置弹窗；VIP 自定义线路进入线路管理表单。

### 提示词与画风库

二者共享“分类筛选 + 卡片网格 + 新增弹窗”的信息架构。提示词卡片提供复制操作；画风卡片提供图片占位、提示词描述和使用次数。

### 资产库

以角色、场景、道具的网格卡片作为核心浏览方式，顶部提供类型、内容和搜索条件；卡片内使用统一的预览区，便于后续接入真实图片。

### 分镜台

采用三列高密度工作区：原始画面内容、推理后的画面描述、图片结果/拖拽导入。顶部提供批量推理、批量生图、漫画设置和导出漫画；底部提供分页与导入新行。

## 5. 组件状态

- 默认状态：深灰卡片、灰色边框、白色文字。
- Hover：边框转为青绿色。
- Active：青绿色实心按钮或标签。
- VIP/高优先级：金色实心按钮、皇冠符号。
- 可用：青绿色圆点；关闭：灰色空心圆点。
- 空状态：青绿色虚线框，使用“＋”作为主要行动提示。

## 6. 后续接入建议

1. 用真实 API 替换 `app.js` 中的静态样例数据。
2. 将账号池、提示词、画风和资产抽成统一实体模型，小说与分镜通过 `novelId` 关联。
3. 批量推理/生图改为异步任务队列，并在卡片和分镜行上显示任务状态、失败原因与重试。
4. 图片上传、拖拽排序、分页、筛选条件持久化和权限校验接入后端。
5. 生产版建议补充键盘导航、焦点态、错误态、空列表态和确认删除流程。
