# Novel-to-Comic 前端改造设计文档

## 1. 项目概述

### 1.1 改造目标
参考 http://localhost:8768/ (窝瓜元梦漫画工坊) 的前端交互设计，将 novel-to-comic 项目改造为现代化的流程化漫画制作工具，要求 **90% 一致性**。

### 1.2 核心改造点
- **多页面架构**: 首页 → 项目列表 → 工作台 → 设置
- **流程化步骤导航**: 左侧步骤面板 + 右侧内容区域
- **实时进度反馈**: SSE 流式输出 + 进度条
- **项目管理**: 多项目支持、状态持久化、断点续传
- **现代化 UI**: 卡片式布局、响应式设计、微交互动画

### 2.2 页面切换逻辑

```javascript
// 页面状态管理
const screens = ['home', 'projects', 'work', 'settings'];

function switchScreen(screenName) {
  // 隐藏所有页面
  screens.forEach(s => document.getElementById(`screen-${s}`).classList.add('hidden'));
  // 显示目标页面
  document.getElementById(`screen-${screenName}`).classList.remove('hidden');
  // 更新导航状态
  document.querySelectorAll('.nav-btn').forEach(btn => {
    btn.classList.toggle('is-on', btn.dataset.screen === screenName);
  });
  // 更新 body data 属性 (用于 CSS 选择器)
  document.body.dataset.screen = screenName;
}
```

## 4. 交互流程

### 4.1 新建项目流程

```
[首页] → 点击 [新建项目]
   ↓
[工作台] → 输入文本/上传文件
   ↓
点击 [🚀 开始处理]
   ↓
调用 /api/init → 返回步骤列表
   ↓
显示步骤面板 + 准备就绪状态
   ↓
点击 [▶ 执行第1步] → 循环执行各步骤
   ↓
所有步骤完成 → 显示完成状态 + 下载按钮
```

### 4.2 断点续传流程

```
页面加载 → 调用 /api/state
   ↓
有保存状态? → 显示恢复横幅
   ↓
点击 [▶ 继续执行] → 调用 /api/status 获取最新状态
   ↓
恢复步骤面板 → 找到下一个待执行步骤
   ↓
点击 [▶ 继续] → 从断点继续执行
```

### 4.3 项目管理流程

```
点击 [📂 项目管理] → 打开项目列表
   ↓
调用 /api/projects → 显示项目卡片
   ↓
点击项目卡片
   ↓
├─ 已完成 → 加载并查看结果
├─ 进行中 → 加载并继续执行
└─ 当前项目 → 关闭弹窗
```

## 5. API 接口设计

### 5.1 现有接口 (保持不变)

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/init` | POST | 初始化任务 |
| `/api/status` | GET | 获取任务状态 |
| `/api/step/{idx}` | POST | 执行指定步骤 |
| `/api/step/{idx}/stream` | GET | SSE 流式输出 |
| `/api/results/{id}` | GET | 获取步骤结果 |
| `/api/reset` | POST | 重置任务 |
| `/api/download` | GET | 下载结果 |

### 5.2 新增接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/projects` | GET | 获取所有项目列表 |
| `/api/projects/{id}/load` | POST | 加载指定项目 |
| `/api/projects/{id}` | DELETE | 删除项目 |
| `/api/state` | GET | 获取保存的状态 (断点续传) |

### 7.3 关键交互实现

#### 步骤执行
```javascript
async function runStep(idx) {
  // 1. 更新 UI 状态
  state.currentTask.steps[idx].status = 'running';
  renderSteps();
  
  // 2. 启动步骤 (fire-and-forget)
  await fetch(`/api/step/${idx}`, { method: 'POST' });
  
  // 3. 连接 SSE 实时输出
  connectSSE(idx);
  
  // 4. 启动轮询 (备用)
  startPolling(idx);
}
```

#### SSE 流式输出
```javascript
function connectSSE(idx) {
  const es = new EventSource(`/api/step/${idx}/stream`);
  
  es.addEventListener('chunk', e => {
    const data = JSON.parse(e.data);
    appendOutput(data.text);
  });
  
  es.addEventListener('progress', e => {
    const data = JSON.parse(e.data);
    updateProgress(data.done, data.total);
  });
  
  es.addEventListener('done', e => {
    finishStep(idx);
  });
}
```
