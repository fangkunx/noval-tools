## 使用说明

### 启动应用

```bash
# 在项目根目录
cd novel-to-comic

# Maven 构建并运行
mvn spring-boot:run

# 或者打包后运行
mvn package
java -jar target/novel-to-comic-*.jar
```

### 访问应用

打开浏览器访问: `http://localhost:8080`

### 功能演示

#### 1. 首页
- 点击「新建项目」进入工作台
- 点击「继续上次」恢复上次的任务
- 点击最近项目卡片快速打开

#### 2. 项目列表
- 使用筛选按钮切换视图
- 点击项目卡片打开项目
- 点击删除按钮移除项目

#### 3. 工作台
- 输入文本或上传文件
- 设置参数后点击「开始处理」
- 观察步骤面板实时更新
- 查看实时流式输出
- 点击「查看」按钮查看步骤结果
- 点击「重置」按钮重新开始

#### 4. 设置页
- 配置 AI 后端
- 配置图片生成服务
- 设置输出参数

## API 接口

### 现有接口 (保持不变)

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/init` | POST | 初始化任务 |
| `/api/status` | GET | 获取任务状态 |
| `/api/step/{idx}` | POST | 执行指定步骤 |
| `/api/step/{idx}/stream` | GET | SSE 流式输出 |
| `/api/results/{id}` | GET | 获取步骤结果 |
| `/api/reset` | POST | 重置任务 |
| `/api/download` | GET | 下载结果 |
| `/api/state` | GET | 获取保存的状态 |
| `/api/rerun/{idx}` | POST | 从指定步骤重新执行 |

### 项目管理接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/projects` | GET | 获取所有项目列表 |
| `/api/projects/{id}/load` | POST | 加载指定项目 |
| `/api/projects/{id}` | DELETE | 删除项目 |
| `/api/upload` | POST | 上传文本文件 |
