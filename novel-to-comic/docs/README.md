## 🔧 开发指南

### 新项目开发流程

1. **阅读规范**：`DEVELOPMENT_STANDARDS.md`
2. **查看原型**：`docs/prototype-v2.html`
3. **参考截图**：`docs/png/` 目录
4. **编写代码**：遵循分层架构
5. **自检清单**：`CODE_REVIEW_CHECKLIST.md`
6. **提交 PR**：遵循 Commit 规范

### 快速查找

- **命名规范** → `DEVELOPMENT_STANDARDS.md` 第 2 节
- **API 设计** → `DEVELOPMENT_STANDARDS.md` 第 6 节
- **数据库规范** → `DEVELOPMENT_STANDARDS.md` 第 5 节
- **前端规范** → `DEVELOPMENT_STANDARDS.md` 第 7 节
- **新增步骤** → `QUICK_REFERENCE.md`「新增步骤流程」
- **配置说明** → `DEVELOPMENT_STANDARDS.md` 第 8 节
