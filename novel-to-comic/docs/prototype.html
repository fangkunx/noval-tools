📝 交互说明

1. 页面切换

  • 点击顶栏导航按钮切换页面
  • 当前页面按钮高亮显示 (蓝色背景)
  • 页面切换时保留各页面状态

2. 新建项目流程

  • 首页/项目列表点击「新建项目」→ 进入工作台
  • 输入文本/上传文件 → 设置参数 → 点击「开始处理」
  • 系统初始化任务 → 显示步骤面板 → 自动执行第一步
  • 每步完成后可查看结果 → 点击「继续下一步」
  • 全部完成 → 显示完成状态 → 可下载结果

3. 断点续传

  • 页面加载时检查是否有未完成任务
  • 有 → 显示恢复横幅 → 点击「继续执行」
  • 恢复步骤面板状态 → 从断点继续执行

4. 项目管理

  • 项目列表支持筛选：全部/进行中/已完成
  • 点击项目卡片 → 加载项目 → 进入工作台
  • 可进行的操作：查看/继续/删除

5. 实时反馈

  • SSE 实时流式输出执行日志
  • 进度条显示当前步骤进度
  • 步骤面板实时更新状态
