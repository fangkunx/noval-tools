【创作规范】

1、画风要求：精致Q版(Chibi)网漫风格，人物娇小可爱(2-3头身)，面部微表情等夸张灵动，光影自然唯美，层次丰富，完美适配各类题材背景。

2、镜头语言：善用"大环境vs小人物"的定场空间对比，精通视平线调度(如高大角色蹲下与Q版平视)；强调眼神与微距道具交互（如戳脸、牵手、递东西）；避免平视呆板视角，善用仰拍或者俯拍增强情绪。

3、视觉冲击与留白控制：为了完美适配竖屏滑动阅读，在单格/大格布局中，Q版人物的面部或核心互动区域必须占据画面的绝对主导(40%以上比例的"大头特写")。必须为后期嵌字严格预留纯色或新变色的负空(Negative Space)，且负空间绝对避开角色脸部。

【分镜与视觉推导核心法则】

1. **构图与景别节奏（黄金法则）**：
- 严禁平铺直叙！必须采用「建立镜头(全景/中景交代位置) -> 动作镜头(中近景交代交互) -> 情绪特写(局部或脸部大特写)」的连招组合。
- 极其偏爱**面部大特写**（如：咬牙切齿的下半脸、震惊放大的瞳孔）和**身体局部特写**（如：若隐若现的腰线、攥紧的拳头）来传递张力。

2. **高级版式设计**：
- **分格布局**：
- 上下两格(Top-Bottom Split)：经典二分，适合对话。
- 三格斜切 (Diagonal Triple Split)：动态分割，适合情绪变化。
- 中央大格+回忆小格(Central Large + Memory Small)：主次分明，适合插入回忆。
- 镜像对比格(Mirror Contrast Split)：对称布局，适合对比或反思。
- 电影宽银幕式(Cinematic Widescreen)：横版全景，适合宏大场景。
- **画中画/回忆框**：当文本提及过去或联想时，必须在主画面一侧（通常是右上角或背景留白处）叠加边缘羽化或带有灰色滤镜的「回忆画中画」。
- **多格联动**：同一场景内的连续对话或动作，应采用「上下双格」或「一大一小」或「三格斜切」的破格排版，电影宽银幕式。

3. **漫画特效与高级 UI / 字体（商业韩漫级，须在 screen_prompt 中写清）**：
- **对白气泡**：严格采用**白色背景+黑色边框(3-4px)+微软雅黑字体黑色文字**，椭圆形或微圆角胶囊形；**指向尾巴**要细、尖、干净，指向嘴角或额头。情绪激烈时可用**略压扁的宽椭圆**或**带轻微透视的斜向气泡**，仍保持边缘干净。
- 对白内容禁止包含角色名前缀，禁止出现【角色名】、{角色名}、[角色名]等任何形式的人物标注，直接输出角色说的话即可。
- **旁白/叙述条**：需要说明每一天旁白在画面中的位置，严格采用**白色背景(70%-85%不透明度)+黑色边框(3-4px)+微软雅黑字体黑色文字**；位置多在**画面上/下三分之一安全区**，与分格线留出呼吸边距。严格采用**横排自适应画面**，禁止出现**竖排**，无标点，空格断句。禁止所有旁白放一起，单条旁白不超过30字。
- 旁白内容禁止包含旁白前缀，禁止出现【旁白】、{旁白}、[旁白]等任何形式的标注，直接输出旁白内容即可。
- **文字规范**：必须使用**简体中文字体**，禁止使用繁体中文字体。
- **内心独白**：可用**虚线边框小圆角框**或**淡色填充窄条**，字体略细、字距略松，与对白气泡明显区分。
- **层级与禁忌**：旁白条、对白气泡二者**字号与字重须分层**（旁白≤对白主字号）；全页保持**统一的设计语言**（同一套描边/投影强度）。严格从原文提取台词与旁白，禁止大段杜撰。
